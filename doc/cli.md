# C-Ops CLI 가이드

C-Ops CLI(`cops`)는 로컬 프로젝트를 C-Ops 시스템에 등록하고 관리하는 도구입니다. 복잡한 설정 파일을 직접 수정하는 대신, 간단한 명령어로 프로젝트 감시를 제어합니다.

## 사용자 행동 패턴 (User Behavior Patterns)

### 1. 프로젝트 등록 (Project Registration)
사용자는 새로운 프로젝트에서 작업을 시작할 때, 해당 프로젝트를 C-Ops가 추적하도록 등록합니다.

**상황**: `~/workspace/new-feature` 프로젝트에서 Claude Code를 사용하기 시작함.
**행동**:
```bash
cd ~/workspace/new-feature
cops add .
```
**동작**:
1. 현재 디렉토리의 절대 경로를 확인합니다.
2. `~/.cops/config.json` 파일을 읽어 `projects` 목록에 추가합니다.
3. 데몬(Daemon)이 설정 변경을 감지하고, 해당 경로의 `.claude` 디렉토리에 대한 파일 감시(File Watcher)를 시작합니다.

### 2. 프로젝트 동기화 (Syncing History)
이미 많은 작업을 진행한 프로젝트를 뒤늦게 등록할 때, 과거 로그까지 한 번에 수집하고 싶어합니다.

**행동**:
```bash
cops add . --sync
```
**동작**:
1. 프로젝트를 등록합니다.
2. 데몬에게 "제공된 경로의 모든 과거 JSONL 로그를 읽어들이라"는 시그널을 보냅니다 (또는 플래그 설정을 통해 데몬이 수행).
3. 과거 세션 데이터가 API 서버로 전송되어 대시보드에서 히스토리를 볼 수 있게 됩니다.

### 3. 등록된 프로젝트 목록 확인
현재 어떤 프로젝트들이 감시되고 있는지 확인합니다.

**행동**:
```bash
cops list
```
**동작**:
1. `~/.cops/config.json`을 읽어 포맷팅하여 출력합니다.
2. 각 프로젝트의 상태(활성/비활성), Git 브랜치/워크트리 정보 등을 함께 표시합니다.

### 4. 프로젝트 제거
더 이상 추적할 필요가 없는 프로젝트를 제외합니다.

**행동**:
```bash
cops remove .
# 또는
cops remove ~/workspace/old-project
```
**동작**:
1. 설정 파일에서 해당 경로를 제거합니다.
2. 데몬이 변경을 감지하고, 해당 경로에 대한 파일 감시 리소스를 해제합니다.
